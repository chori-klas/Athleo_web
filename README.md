# ATHLEO

Sitio web estático de ATHLEO, una tienda de material deportivo. No necesita instalación de dependencias ni proceso de compilación.

## Estructura

- `index.html`: página de inicio y punto de entrada del sitio.
- `styles.css`: estilos compartidos.
- `fotos/`: logotipo e imágenes de productos.
- `archivos_html/`: páginas de categorías, ofertas, inventario y contacto.

## Vista local

Abre `index.html` en un navegador. Los enlaces y recursos usan rutas relativas, por lo que también funcionan al publicar el repositorio como un sitio estático.

## GitHub Pages

En la configuración del repositorio, activa GitHub Pages desde la rama principal y selecciona la carpeta raíz (`/(root)`). GitHub Pages utilizará `index.html` como página de inicio.
